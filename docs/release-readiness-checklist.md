# Release Readiness Checklist (PDF Truth MVP)

## 릴리즈 전 필수 확인 사항
- [ ] master가 최신 상태인지 확인
- [ ] 대상 PR이 최신 master와 충돌 없는지 확인
- [ ] CI 상태가 녹색인지 확인
- [ ] 릴리즈 대상 커밋/태그 후보 확정
- [ ] README 및 제한사항 문서 최신화

## 기능 체크리스트
- [ ] PDF 파일 선택 동작 확인
- [ ] PDF 렌더링 정상 동작 확인
- [ ] 여러 페이지 스크롤 정상 동작 확인
- [ ] 페이지 이동(상/하, 직접 이동) 확인
- [ ] Pinch Zoom / Double Tap Zoom 확인
- [ ] 썸네일 열기/닫기/탭 이동 확인
- [ ] 최근 문서 목록 및 재열기 확인
- [ ] 마지막 읽은 페이지 복원 확인
- [ ] 북마크 추가/삭제/반영 확인
- [ ] PDF 메타데이터 표시 확인
- [ ] PDF 검색 실행 및 결과 이동 확인

## 오류 처리 체크리스트
- [ ] 권한 만료/거부 시 사용자 안내 문구 확인
- [ ] 파일 삭제/이동 시 오류 안내 확인
- [ ] 손상/미지원 PDF 안내 확인
- [ ] 검색 실패 시 안내 문구 확인
- [ ] 검색 취소 시 상태 복구 확인
- [ ] 중복 검색 실행 방지 확인

## 성능 체크리스트
- [ ] 대용량 PDF(페이지 수 많은 문서)에서 첫 진입 지연 확인
- [ ] 스크롤 시 렌더링 지연 체감 확인
- [ ] 썸네일 표시 시 메모리 급증 여부 확인
- [ ] 검색 실행 중 UI 응답성 확인
- [ ] 저사양 기기에서 기본 기능 사용 가능 여부 확인

## 개인정보/오프라인 체크리스트
- [ ] 개인정보 수집 로직 없음 확인
- [ ] 광고 SDK 없음 확인
- [ ] 로그인/계정 기능 없음 확인
- [ ] 외부 서버 호출 없음 확인
- [ ] 오프라인 사용 중심 동작 확인

## GitHub PR/CI 체크리스트
- [ ] master 직접 commit 없음
- [ ] master 직접 push 없음
- [ ] 작업 브랜치에서만 변경
- [ ] PR 제목/본문 규칙 준수
- [ ] 최소 1회 이상 리뷰 확인
- [ ] GitHub Actions 최근 실패 원인 점검

## 배포 전 보류 항목
- [ ] PR #9 리뷰 및 병합 완료
- [ ] 최근 실패한 CI 원인 정리 및 재검증
- [ ] release 후보 태그 전략 확정
- [ ] APK/AAB 산출물 생성 경로 점검
- [ ] 스토어 메타데이터/아이콘 준비

# PDF Truth (True’s) PDF 검색 엔진 도입 검토

## 1. 검토 목적
- PDF Truth의 검색 기능 고도화를 위해 PdfRenderer 한계와 대안(PDFium, MuPDF) 도입 가능성을 기술적으로 검토한다.

## 2. 현재 구조 요약
- Android PdfRenderer 기반 PDF 렌더링 및 LazyColumn UI 구현
- PdfSearchEngine 인터페이스 구조만 존재, 실제 텍스트 검색은 미구현
- 오프라인, 광고/트래킹 없는 무료 앱 정책

## 3. Android PdfRenderer 검색 한계
- 텍스트 추출 불가(이미지 렌더링 전용)
- 페이지 내 텍스트 위치/검색 불가
- 하이라이트/검색 결과 표시 불가
- 오픈소스 PDFium/MuPDF 등 외부 엔진 필요

## 4. PDFium 검토
- Google/Chromium 기반 오픈소스 PDF 엔진
- 텍스트 추출/검색/하이라이트 지원
- JNI 연동 필요, 빌드/설정 복잡
- 라이브러리 용량 증가(수 MB)
- 오프라인 사용 가능
- BSD 라이선스(상업/무료 앱 모두 허용)
- Android 적용 사례 다수(예: pdfium-android)

## 5. MuPDF 검토
- Artifex 오픈소스 PDF 엔진
- 텍스트 추출/검색/하이라이트 지원
- JNI 연동 필요, 빌드/설정 복잡
- 라이브러리 용량 증가(수 MB)
- 오프라인 사용 가능
- AGPL/상용 라이선스(무료 앱은 AGPL 준수 필요)
- Android 적용 사례 다수

## 6. 라이선스 검토
- PDFium: BSD(제약 적음, 무료/상업 모두 허용)
- MuPDF: AGPL(코드 전체 공개 필요), 상용은 유료
- 전면 무료 앱은 PDFium이 리스크 적음

## 7. 전면 무료 앱 정책과의 적합성
- PDFium: 무료/오픈소스 정책과 호환
- MuPDF: AGPL 준수 필요(코드 전체 공개, 배포 제약)

## 8. 성능/용량/구현 난이도 비교
| 기준                | PdfRenderer | PDFium      | MuPDF       |
|---------------------|-------------|-------------|-------------|
| 텍스트 추출         | 불가        | 가능        | 가능        |
| 검색 결과 매칭      | 불가        | 가능        | 가능        |
| Android 적용 난이도 | 쉬움        | 어려움      | 어려움      |
| 라이브러리 용량     | 작음        | 큼(수 MB)   | 큼(수 MB)   |
| 렌더링 성능         | 우수        | 우수        | 우수        |
| 오프라인 사용       | 가능        | 가능        | 가능        |
| 라이선스 리스크     | 없음        | 낮음        | 높음(AGPL)  |
| 무료 앱 적합성      | 우수        | 우수        | 제한적      |
| 하이라이트 확장성   | 불가        | 가능        | 가능        |
| 유지보수 난이도     | 쉬움        | 어려움      | 어려움      |

## 9. PdfSearchEngine 인터페이스와 연결 방법
- PDFium/MuPDF JNI 래퍼 구현 후, PdfSearchEngine 구현체로 연결
- 텍스트 추출/검색 결과를 기존 UI와 연동
- 하이라이트/검색 결과 표시 기능 확장 가능

## 10. 최종 권장 방향
- PDF Truth의 정책(오프라인, 무료, 오픈소스, 광고/트래킹 금지)에 가장 적합한 엔진은 PDFium
- MuPDF는 AGPL로 인해 전체 코드 공개/배포 제약이 크므로 권장하지 않음
- PDFium 기반 JNI 래퍼 및 PdfSearchEngine 구현체 개발 권장

## 11. 다음 구현 단계 제안
- PDFium 기반 텍스트 추출/검색 기능 구현
- PdfSearchEngine 구현체 작성
- 검색 결과 하이라이트/페이지 이동 UI 연동
- MuPDF는 추후 필요 시 별도 브랜치에서 실험

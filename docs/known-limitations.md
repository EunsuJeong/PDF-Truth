# Known Limitations

## 현재 제한사항
- Android PDF 렌더링/검색 구조가 완전한 상용 엔진 수준은 아님
- 일부 문서에서 기기/OS 버전에 따라 체감 성능 차이가 발생할 수 있음

## PDFium 검색 제한 가능성
- PDFium 준비 의존성은 포함되어 있으나, 검색 품질/동작은 문서 특성과 엔진 상태에 영향받을 수 있음
- PdfRenderer 기반 fallback 경로에서는 텍스트 검색 지원이 제한될 수 있음

## 대용량 PDF 성능 이슈 가능성
- 페이지 수가 매우 많은 PDF에서 초기 로딩 시간이 증가할 수 있음
- 썸네일/렌더링 캐시 정책에 따라 메모리 사용량이 일시적으로 증가할 수 있음
- 검색 실행 시 문서 크기에 따라 결과 반환 지연이 발생할 수 있음

## 기기별 성능 차이
- 저사양 기기에서 스크롤/줌 응답성이 떨어질 수 있음
- 고해상도 화면에서 렌더링 비용이 증가할 수 있음
- 제조사별 WebView/그래픽 드라이버 환경 차이가 체감 성능에 영향 줄 수 있음

## 향후 개선 예정
- 검색 엔진 품질 및 정확도 개선
- 대용량 문서 대응 성능 튜닝
- 기기 프로파일 기반 성능 가이드 정리
- 릴리즈 기준 회귀 테스트 시나리오 고도화
